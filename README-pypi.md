# pyRockImageLab

v0.1.2

pyRockImageLab turns geological core photographs into clean, depth-labelled images. It crops and straightens core sections from whole core-box photographs and stitches close-up photographs into long, high-resolution images.

A local browser app provides two workflows: crop core-box photos and stitch close-up photos. Corner selections are saved with each photo folder so processing can be repeated from Python, notebooks, or the command line without further clicking.

The package requires Python 3.10 or newer. Installation details, examples, and demonstrations are in the [GitHub repository](https://github.com/GeoLarryLai/pyRockImageLab).

Citation: Lai, L. S.-H. (2026). pyRockImageLab. [Zenodo](https://doi.org/10.5281/zenodo.23656974).
