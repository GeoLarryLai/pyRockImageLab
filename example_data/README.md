# Example data

`ExampleCore/2563-2572/` is a small, anonymized example set used by
`pyRockImageLab_1_ExampleCore.ipynb`:

- `ExampleCore_00_box.jpg`: overview photo of one core box (2563–2572 ft, three 3-ft segments), downscaled
- `ExampleCore_01_detail.jpg` to `ExampleCore_06_detail.jpg`: close-up photos of segment 1 (2563–2566 ft)
- `_picks.json`: saved corner picks (box segments, per-photo crops, mosaic ortho quad)

Well identifiers were removed from all names, and photo metadata (EXIF/GPS) was stripped. Photos are JPEG-recompressed to keep the set at about 15 MB.
The images are shared for demonstration and reproducibility only; please credit this repository if you reuse them.
